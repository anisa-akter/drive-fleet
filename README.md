# DriveFleet Car Rental Platform

Live Site: https://drivefleet.example.com

## Overview
DriveFleet is a premium car rental platform where guests can browse curated fleets, book rentals, and manage bookings, while hosts can add, update, and manage their own listings.

## Key Features
- Secure authentication with JWT cookies and protected private routes.
- Explore cars with search and type filters plus detailed vehicle pages.
- Booking flow with driver preference, notes, and booking history.
- Host dashboard for adding, updating, and removing car listings.
- Responsive, recruiter-friendly UI with consistent typography and layout.

## Tech Stack
- Next.js App Router
- Tailwind CSS + DaisyUI
- Express.js API (separate server project)

## Local Development
1. Install dependencies: `npm install`
2. Start the dev server: `npm run dev`
3. Update `NEXT_PUBLIC_API_BASE_URL` in `.env.local` for your API.
